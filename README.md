# party-sync

Браузерная викторина на 50 ходов для голосового созвона в Discord. Один человек открывает главный экран (Stage) и включает демонстрацию, остальные подключаются с телефонов по QR-коду как пульты.

Ссылка: https://sup3dev.github.io/party-sync/

## Как устроено

- **Экран ведущего (Stage)** — создаёт комнату с 4-символьным кодом и QR-кодом, показывает текущий вопрос, счёт и события.
- **Пульт игрока (Controller)** — открывается с телефона по QR-коду или прямой ссылке `?room=XXXX`. В свой ход на телефоне выбираешь ответ, двигаешь ползунок или применяешь джокеры (`50/50`, `×2`, `помощь друга`, `передать вопрос`, `подсказка`). В чужой ход можно ставить на исход ответа (`+100` / `-50`) и отправлять реакции на общий экран.
- **Типы вопросов** — выбор из 4 вариантов, «правда или вымысел», числовой ползунок на интуицию и вопросы про участников комнаты. Каждый 4-й ход запускается барабан событий (три шкатулки, дуэль 1 на 1, сделка или подстава, перекуп вслепую, кража очков у лидера).

## Свои вопросы через YandexGPT (опционально)

Ключ и `Folder ID` вводятся в настройках на странице и хранятся только в `localStorage` браузера. Если браузер режет прямой запрос с `github.io` к `llm.api.cloud.yandex.net` по CORS, на компьютере ведущего можно запустить локальный прокси:

```bash
node yandex-bridge.mjs
```
