# ⚡ ВЕЧЕРНИЙ СИНК (Party Sync Show — 6 Players Edition)

Интерактивный комбайн из **4 вечерних Party-игр** для компании в Discord (идеально сбалансировано под команду **3 Менеджера 📊 + 3 Программиста 💻**). Работает прямо на **GitHub Pages** без собственного сервера!

👉 **Играть онлайн:** [https://sup3dev.github.io/party-sync/](https://sup3dev.github.io/party-sync/)

---

## 🎮 4 Игровых Режима (можно играть единым ТВ-Шоу или по отдельности)

1. **🎯 50 Вопросов 2.0 (Квиз-Рулетка + Джокеры + Ивенты + Ставки зала)**
   - Игроки отвечают по очереди, а **остальные 5 участников делают ставки** («👍 Ответит» / «💀 Засыпется») на каждом ходе.
   - У каждого в арсенале **6 Джокеров**: `50/50`, `Ва-Банк ×2`, `Консилиум (помощь друга)`, `Перевод стрелок`, `Голос Discord`, `Нейро-намёк от YandexGPT`.
   - Каждые 3 хода выпадают **Случайные Ивенты**: *Чёрный Ящик*, *Дилемма коллег (Сотрудничать или Крысить)*, *Робин Гуд*, *Турбо-блиц*, *Двойные ставки*.
2. **🎭 Правдоруб (Fibbage Блеф-Клуб)**
   - Безумные, но реальные факты из мира технологий, бизнеса, кино и истории с пропуском.
   - Игроки тайно вписывают правдоподобную ложь (или играют в быстром режиме на одном экране) и пытаются заманить коллег в ловушку (+300 за каждого обманутого, +400 за найденную правду).
3. **📡 На одной волне (Wavelength / Спектр мнений)**
   - Активный игрок («Телепат») подсматривает секретную точку на шкале от `0%` до `100%` между двумя полюсами (например, *«Легко пообещать клиенту» ◄───► «Невозможно запрограммировать»*) и называет одну ассоциацию.
   - Команда в Discord обсуждает и двигает стрелку спидометра, а соперники ставят «Левее / Правее».
4. **🤖 Кейс-Баттл с ИИ-Арбитром (YandexGPT)**
   - Нестандартные командные ситуации + случайное смешное условие-мутатор.
   - Игрок озвучивает план спасения (поддерживается **🎙️ голосовой ввод Web Speech API** прямо в браузере!), а **YandexGPT** (или встроенный судья) выдаёт остроумный вердикт и начисляет от 150 до 500 очков!

## 📱 Как играть в Discord

- **Способ 1 (Чисто через Демонстрацию Экрана):** Ведущий открывает сайт, включает демонстрацию экрана со звуком в Discord, и все играют голосом.
- **Способ 2 (Гибрид с телефонами/вкладками через WebRTC P2P без сервера):** Ведущий нажимает в шапке кнопку **«Пульты с телефонов (P2P)»** и кидает ссылку с кодом комнаты в чат Discord. Коллеги заходят со своих устройств и жмут ответы, ставки и блефы со своих экранов!

## 🔒 Подключение приватного ключа Yandex Cloud API

1. Ключ вводится в модалке **«Yandex Cloud AI»** в правом верхнем углу и сохраняется **только в `localStorage` браузера ведущего** (в репозиторий ничего не попадает).
2. Если браузер блокирует прямой запрос с `github.io` к `llm.api.cloud.yandex.net` по CORS, ведущий может запустить локальный микро-мост из корня репозитория (0 зависимостей, стандартный Node.js 18+):
   ```bash
   node yandex-bridge.mjs
   ```
   После этого сайт на GitHub Pages автоматически увидит `http://127.0.0.1:31337` и сможет генерировать бесконечные новые вопросы на любую тему и судить ответы через YandexGPT!
